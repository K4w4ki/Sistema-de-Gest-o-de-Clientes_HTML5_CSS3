# Sistema de Gestão de Clientes

## Objetivo

Este projeto foi desenvolvido como trabalho da disciplina de Desenvolvimento Web, com o objetivo de criar uma interface gráfica para um sistema de gestão de clientes utilizando apenas **HTML5** e **CSS3**.

O foco do trabalho foi aplicar os conceitos de HTML semântico, organização do CSS, responsividade e acessibilidade.

---

## Tecnologias Utilizadas

- HTML5
- CSS3

Neste projeto não foram utilizados JavaScript, frameworks ou bibliotecas externas.

---

## Estrutura do Projeto

```
/
├── index.html
├── style.css
├── README.md
└── relatorio.md
```

---

## Como Executar

1. Baixe todos os arquivos do projeto.
2. Coloque os arquivos na mesma pasta.
3. Abra o arquivo `index.html` em qualquer navegador moderno.

Não é necessário instalar programas ou configurar servidor.

---

## Funcionalidades

O sistema possui:

- Cabeçalho com identificação do sistema;
- Menu de navegação;
- Formulário para cadastro de clientes;
- Tabela para visualização dos clientes cadastrados;
- Painel lateral com informações complementares;
- Rodapé com informações do sistema.

---

## Responsividade

A interface foi desenvolvida para funcionar em diferentes tamanhos de tela.

Foram utilizadas **Media Queries**, permitindo que o layout se adapte a computadores, tablets e celulares.

---

## Acessibilidade

Durante o desenvolvimento foram aplicadas algumas boas práticas, como:

- utilização do atributo `lang="pt-BR"`;
- labels associadas aos campos do formulário;
- hierarquia correta de títulos;
- contraste adequado entre texto e fundo;
- HTML semântico.

---

## Autor

Projeto desenvolvido como atividade acadêmica da disciplina de Desenvolvimento Web.

## Observações

Este projeto possui apenas a interface da aplicação, sem integração com banco de dados ou JavaScript. Seu objetivo é demonstrar a utilização de HTML5 e CSS3 na construção de uma interface organizada, responsiva e acessível.
